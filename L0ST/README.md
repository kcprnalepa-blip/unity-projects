# L0ST

A fast-paced arcade game built in Unity, focused on movement, aiming and surviving against incoming asteroids.

## About

L0ST is a small arcade game created for a game jam.

The player controls a spaceship and must survive while destroying incoming asteroids using a laser beam.

The game focuses on simple controls, quick reactions and arcade-style gameplay.

## Features

* Spaceship movement
* Mouse-controlled laser
* Asteroid enemies
* Arcade-style gameplay
* Score-based gameplay
* Game jam project

## Built With

* Unity
* C#

## My Work

For this project, I worked on the gameplay systems, including the player movement, laser mechanics, asteroid behaviour and game logic.

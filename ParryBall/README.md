# ParryBall

A local 1v1 arcade game built in Unity, focused on timing, reactions and positioning.

## About

ParryBall is a two-player game played on a single keyboard.

Players must **parry a ball** at the right moment, sending it back toward their opponent. The ball moves similarly to the classic Pong, but instead of simply hitting it, players need to time their parries.

The scoring system is inspired by **volleyball**: if the ball touches a player's side of the arena, the opponent scores a point.

## Features

* Local 1v1 multiplayer
* Single-keyboard controls
* Timing-based parry mechanic
* Pong-inspired ball movement
* Volleyball-inspired scoring
* Simple main menu
* Fast-paced arcade gameplay
